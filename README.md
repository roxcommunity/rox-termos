# Rox Community — Regras

Site estático das regras oficiais da Rox Community, preparado para GitHub Pages.

## Estrutura

- `index.html` — página principal
- `assets/styles.css` — estilos
- `assets/app.js` — regras, navegação e pesquisa
- `.github/workflows/pages.yml` — publicação automática no GitHub Pages

## Publicação

Envie os arquivos para a branch `main`. O workflow `pages.yml` publica o site automaticamente no GitHub Pages.
